# Seaynic Labs Homebrew tap

**Made by [Seaynic Labs](https://seayniclabs.com).** Need tools like this built around your own systems? [We do that](https://seayniclabs.com/#business).

This tap holds the Homebrew formulae for Seaynic Labs tools.

## Install

```bash
brew install seayniclabs/tap/bench
```

Homebrew adds the tap the first time you install from it.

## Formulae

| Formula | What it installs |
|---|---|
| `bench` | Bench, a USB hardware discovery MCP server for maker boards (Arduino, ESP32, Raspberry Pi Pico). It builds from source with Swift and needs Xcode 16.3 or later. |
| `stdout-scanner` | A scanner for your Docker host that prints a Markdown or JSON report of containers, ports, networks, volumes and host facts. Apple silicon only. |

The formulae are in [`Formula/`](Formula/).
